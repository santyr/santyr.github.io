# Bitcoin and the Alignment of Autonomous Agents

*From Timothy Leary and Extropianism to a Substrate-Independent Economy of Reputation*

A long-form essay exploring Bitcoin as an economic foundation for alignment among autonomous agents of any substrate.

## Publication assets

- [Full essay — Markdown](article.md)
- [Standalone summary — Markdown](summary.md)
- [Extropian-inspired hero artwork — SVG](hero.svg)

These assets are deliberately separate for use in Nostr long-form publishing. Neither the summary nor the hero image is embedded in the article.

## Research companion

- [The Agoric Alignment Experiment](agoric-alignment-experiment/README.md) — an agent-executable research package testing the essay's substrate-independent alignment thesis using pseudonymous identity, competing reputation evaluators, reproducible economies, Archon and optional Bitcoin anchoring. Includes historical sources, hypotheses, studies, threat models, stages, task backlog, JSON schemas and configuration examples.

This is a **planned research program**, not an assertion that its experiments have run or proved the thesis. The article, its separate summary and the hero artwork remain unchanged.
